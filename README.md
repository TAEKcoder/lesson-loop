**Lesson Loop — 수업용 음악 플레이어**

[플레이어 열기](https://ktlee-coder.github.io/lesson-loop/)

선생님별 수업곡과 1~4주차 구간을 저장하고, 수업 중 큰 시간 표시와 간단한 버튼으로 음악을 조작합니다.

- 구간 반복, 1배속·음정 유지 0.8배속, 부드러운 페이드 인·아웃
- 준비운동 재생목록, 다음 곡 자동 재생, 목록 반복과 순서 변경
- 원본을 보존하는 앞뒤 재생 범위 편집과 무음 구간 제안
- Safari 호환 출력, 브라우저 내 음원 저장, 음원 포함 백업
- 사용자가 업데이트 버튼을 눌러야 적용되는 버전 관리

음원과 수업 설정은 사용하는 브라우저에 저장됩니다. 음악 파일, 개인 백업, 음원이 포함된 단일 HTML 파일은 이 저장소와 공개 사이트에 포함하지 않습니다. 다른 사이트나 브라우저에서 옮겨 오려면 기존 플레이어의 ‘설정 · 백업’에서 음원 포함 백업을 내려받고 새 플레이어에서 불러오세요.

개발에는 Node.js 24와 Python 3를 사용합니다. 외부 패키지 설치는 필요하지 않습니다.

```sh
node --test *.test.mjs
python3 build-github-pages.py
python3 -m http.server 8000 --directory _site
```

`next/`는 작업 소스, `dist/releases/<version>/`은 배포된 버전입니다. 기존 버전은 그대로 두고 `prepare-release.py`의 버전을 올려 새 폴더를 생성한 뒤 `dist/release.json`을 갱신하세요. `main`에 올리면 GitHub Actions가 검사와 Pages 배포를 진행합니다. 실행 중인 플레이어는 자동으로 새 버전으로 바뀌지 않습니다.

`build-github-pages.py`는 GitHub 프로젝트 경로에 맞춘 `_site/`를 생성합니다. 업데이트 경로와 브라우저 저장소는 프로젝트별로 구분됩니다. 기존 호스팅의 비공개 메타데이터는 공개 사본에서 제외했습니다.
